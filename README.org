Showcase in a pretty way all the available Guile packages in the Guix repository, to promote adoption of this great and powerful language, and to make the ecosystem better.

Thanks to Lisp's homoiconicity we can analyze Lisp/Scheme source code directly from: https://codeberg.org/guix/guix/raw/branch/master/gnu/packages/guile-xyz.scm

See the live version at: https://jointhefreeworld.org/guile-show-hub/

If you like my work, please support me by [[https://bmc.link/jjbigorra][buying me a cup of coffee ☕]] so I can continue with a lot of motivation.
